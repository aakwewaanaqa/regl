# Regl 命令行处理库

这个目录包含了处理命令行参数的类型和构建器。

## 命名空间结构

- `Regl.CommandLine.Types`: 包含所有与命令行处理相关的基本类型
  - `Flags.fs`: 定义了标志接口和实现
  - `ParseResult.fs`: 定义了解析结果类型
  - `CommandBody.fs`: 定义了命令体类型

- `Regl.CommandLine.Builders`: 包含用于构建命令的工具
  - `CommandBuilder.fs`: 定义了命令构建器

## 设计理念

使用命名空间来组织类型，这样可以：

1. 提高代码的可重用性
2. 使类型定义与实现分离
3. 提供更清晰的依赖关系
4. 便于将来扩展

命令实现应当保持在模块中，而类型定义则保持在命名空间中。
