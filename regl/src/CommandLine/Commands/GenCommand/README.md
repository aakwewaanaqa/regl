# Regl gen 命令模組來源文件指令

這個函式庫定義在 gen 指令中來源文件可以使用的指令，
指令是用於輸出產生文件的。
從來源文件中透過註解的方式下指令，
可以改變輸出文件的內容。

## 可用指令

### add-evcm

添加環境變數上下文匹配器。這個指令需要三個參數：
1. 正則表達式模式 - 用於匹配源文件中的特定內容
2. 格式字符串 - 定義如何格式化匹配到的內容
3. 環境變數名稱 - 匹配到的內容將被設置到這個環境變數中

```
add-evcm "pattern" "format" "ENV_VAR_NAME"
```

### set-envar

設置環境變數的值。

```
set-envar "ENV_VAR_NAME" "value"
```

### unset-envar

清除指定的環境變數。

```
unset-envar "ENV_VAR_NAME"
```

## 工作原理

當執行 gen 命令時，系統會掃描來源文件中的註解指令，並按照這些指令來處理文件內容和環境變數。這使得在生成過程中可以動態調整輸出內容，根據源文件中的特定模式設置環境變數，然後在模板或其他生成步驟中使用這些變數。

## 使用案例

- 從源代碼中提取版本號、作者信息等並設置為環境變數
- 在生成過程中基於源文件內容動態調整輸出
- 創建自定義生成流程，使用環境變數在不同生成步驟之間傳遞信息

## 注意事項

- 確保正則表達式模式足夠具體以避免錯誤匹配
- 環境變數僅在當前生成過程中有效
